# Put things where they belong

A conceptual CRAM research activity (generated by `ccram new put-away`).

| file | what |
|---|---|
| `activity.toml` | what the activity is made of: ontology modules, library, rules, twin, workbench port |
| `ontology/put.ttl` | the activity's ontology module (D9: defines the words of its language) |
| `library/put.lisp` | action schemas (`:telos` goal templates, D10), plan schemas, failures (Q2), microtheories |
| `rules/put-rules.lisp` | `def-rule`: state-dependent knowledge, forward-chained over the observed atoms |
| `adapter.py` | the twin side: state atoms, servants, realisations, emulation |
| `scenarios.py` | disturbances and initial-state variants |
| `tests/` | lint, goal coverage, runs |

    ccram lint .            ccram goals .           ccram reason .
    ccram run . --plan examine-an-item [--scenario all-examined]
    ccram run . --workbench                          # http://127.0.0.1:8795/
